# Resume

Start this session from where the last one ended.

## Steps

1. Find the status doc for this project.
   - Pasted or attached in this thread? Use it.
   - In a connected Chief Vault? Search for files named
     "STATUS — [project]". There will be several, dated. Read ONLY the
     most recent. Ignore the rest.
   - A file in a Cowork folder? Read it.
   - Can't find one? Say so and stop. Do not guess.
2. Read all of it. The basics, status now, decisions, ruled out,
   open questions, next actions.
3. Tell me in under 100 words:
   - Where we are.
   - What's next. The top item from Next actions.
   - Anything in Open questions that's waiting on me.
4. Name the file you read and its date. If it's more than a week old,
   say so out loud.
5. Stop. Do not start work until I tell you what we're doing.

## Rules

- Never invent state. If the doc doesn't say it, you don't know it.
- Nothing under "Ruled out" gets reopened. That's settled.
- If the doc contradicts itself, flag it. Do not pick a side.
- Reading an old version poisons everything after it. If you're not
  certain which is most recent, ask.
