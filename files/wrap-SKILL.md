# Wrap

Close out this work session so the next one starts where this one ended.

## Steps

1. Find the current Status. It was probably pasted in near the top of
   this thread. If it lives in a connected Chief Vault, find every file
   whose name starts with "STATUS" for this project and read only the
   MOST RECENT one. Ignore the older ones. If you can't find it, say so
   and ask.
2. Look back over this thread and pull out only what changed:
   - Decisions made. Not topics discussed. Decisions.
   - Things ruled out, and the reason why.
   - Questions still open.
   - The single next move.
3. Rewrite Status. Do not append. Rewrite it so it reads as
   "here is where we are now," not "here is what happened."
4. Keep it under one page. Cut anything that is settled and no longer
   shapes the next move.
5. Deliver it the way this setup allows:
   - No connector: output the whole rewritten Status in one block I can copy.
   - Connected Chief Vault: save it as a NEW file named
     "STATUS — [project] — [today's date]". Do not try to edit the old
     one, you can't. Do not delete the old one, you can't. Leave it.
   - Cowork: rewrite the Status file in place. Same file.

## Rules

- Decisions, not discussion. "We talked about pricing" is worthless.
  "Pricing is $2,400, flat, no tiers" is the whole point.
- If something was ruled out, say why. Future me will ask.
- If two things in this thread contradict each other, do not pick one.
  Flag both and ask.
- Never delete an open question just because nobody mentioned it again.
